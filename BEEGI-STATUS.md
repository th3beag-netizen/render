# Beegi 26.3 development branch

This branch contains a compressed snapshot of the Beegi 26.3 source (beegi-source.tar.xz) and a GitHub Actions workflow that extracts it and performs an actual Java 25/Fabric build. The source port is incomplete, and no successful 26.3 compile or gameplay test is claimed until Actions proves it. The source project contains a GPLv3 notice; see the original source ZIP from the conversation for the full license and legacy module inventory.
